# agentforce-foundry
Installable Agentforce starters with proof, not just recipes.
Service, Sales, and Internal Ops kits with Apex actions, permission sets, sample data, Testing Center suites, and CI.
Start with Service Triage, live now. Sales and Internal scaffold next.
Quickstart: create a scratch org, deploy force-app, assign Foundry Service permission set, run Apex tests, load tests/testing-center/service-triage.json in Testing Center.
Offline check with no org: run python3 tests/harness/test_validate_kits.py.
Independent project. Not affiliated with Salesforce. Agentforce is a Salesforce trademark.
